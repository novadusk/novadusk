### 📌 Core Projects & Engineering Practices

- **🔭 Linux Kernel & Observability**
  - **[MemScope-Guard](https://github.com/novadusk/MemScope-Guard)**: Linux memory pressure and fragmentation evidence diagnostics with eBPF & Python.
  - **[linux-physical-memory-fragmentation-detector](https://github.com/novadusk/linux-physical-memory-fragmentation-detector)**: eBPF-based tooling for inspecting physical memory external fragmentation.

- **⚡ Embedded & Real-Time Control**
  - **[stm32-freertos-range-hood-controller](https://github.com/novadusk/stm32-freertos-range-hood-controller)**: STM32F103 & FreeRTOS real-time controller featuring PID closed-loop control, sensor integration, UART/DMA, and reliable IAP bootloader.

- **🤖 Industrial Edge & Robotics**
  - **[mine-inspection-platform-mimo](https://github.com/novadusk/mine-inspection-platform-mimo)**: Multi-modal mine inspection robotic platform integrating edge perception, robot dispatching, and verification pipelines.
